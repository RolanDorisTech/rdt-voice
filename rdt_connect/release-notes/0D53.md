# RDT Connect v0.2.0-dev.10.0D.53 — Build 0D53

Development prerelease for macOS on Apple Silicon (arm64). Minimum macOS version: 14.0.

## What's changed

- Restores the dedicated native macOS About panel instead of redirecting About to an in-app section.
- Removes the duplicated full version display by using numeric macOS bundle build metadata.
- Refines the About panel with `Build 0D53`, “Local AI Made Easy”, © 2026 Rolan & Doris Tech, and separate RDT Voice GitHub and RolanDorisTech YouTube links.
- Rebuilds the custom installer with the approved Finder presentation and installation guide.

## Installation and macOS security

- Install manually from the attached custom DMG. Replace the prior RDT Connect app in Applications.
- This build is ad-hoc signed and is not notarized by Apple. macOS may show a first-launch security warning.
- This release includes the custom DMG only. Updater-signed artifacts are not included, and automatic updating is not verified for Build 0D53.
