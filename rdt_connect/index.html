How private access works

Tailscale provides the private encrypted route; the QR code only requests browser access.

Checking local HTTPS configuration…
Manage existing certificates · advanced

RDT Connect creates a local certificate authority for localhost and 127.0.0.1, then offers to add that CA to your system trust store. Your CA private key remains on this Mac. Never share it.

Server certificateNot selected
Matching private keyNot selected
Root CA / trust anchor (optional for a publicly trusted certificate)Not selected

For existing files, select the certificate and matching private key, then click Link certificate. If the certificate uses a private CA, select that self-signed root CA and click Trust root CA. The certificate must be unexpired, match the key, and include IP Address:127.0.0.1 in its Subject Alternative Name (SAN). RDT Connect uses the selected files in place; it does not copy your private key or certificates. Keep those paths stable, and update or relink the files when the certificate renews.

For phone access, use Remote Access. Do not install this device’s local certificate authority on your phone.
